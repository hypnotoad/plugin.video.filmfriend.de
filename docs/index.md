# Filmfriend Kodi Add-on for LibreELEC getting prompt updates required due to authentication changes for 'Stadtbibliothek Stuttgart'

Independent Filmfriend video add-on for Kodi 21 Omega, LibreELEC and Python 3,
maintained by macsobeck.

This fork ensures prompt updates, which are required due to changes to the authentication logic via the 'Stadtbibliothek Stuttgart',
resolves recurring issues with the ‘Login has expired’ message, and supports Widevine playback on Kodi 21 Omega.
