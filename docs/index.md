# Filmfriend Kodi Add-on for Kodi 21 Omega and LibreELEC

Independent Filmfriend video add-on for Kodi 21 Omega, LibreELEC and Python 3,
maintained by macsobeck.

This fork provides current authentication support for Stadtbibliothek Stuttgart,
resolves recurring “Login expired” problems and supports Widevine playback on
Kodi 21 Omega.

[Download the latest Kodi installation ZIP](https://github.com/macsobeck/plugin.video.filmfriend.macsobeck/releases/latest)
